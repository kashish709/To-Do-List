📝 To-Do List Application

This repository contains a simple To-Do List application built using Python and web technologies.
The project demonstrates the ability to create interactive applications that help users organize tasks efficiently.

🚀 Project Overview

The To-Do List app allows users to:

Add tasks

Mark tasks as completed

Remove tasks

Store and display organized task lists

It’s built with simplicity and clarity in mind, aimed at demonstrating basic application logic and interactive UI integration.

📌 How to Run the Project

Clone the repository

git clone https://github.com/kashish709/To-Do-List.git

Navigate to the folder

cd To-Do-List

Open the project in an IDE (VS Code recommended)

If the application has a Python script, run:

python <filename>.py

If it uses HTML/CSS/JS front-end, open the HTML file in your browser.
